# Huffman File Compression

## 📖 Overview

This project implements the Huffman Coding algorithm for lossless file compression using Python.

It reads text from an input file, generates Huffman codes based on character frequencies, compresses the text, and reconstructs the original text through decompression.

---

## ✨ Features

- Read text from a file
- Count character frequencies
- Build Huffman Tree using Min Heap
- Generate Huffman Codes
- Encode text
- Decode text
- Save compressed and decompressed files

---

## 🛠 Technologies Used

- Python
- heapq
- Binary Tree
- Recursion
- File Handling
